# Vokabel Master+

Ein moderner Vokabeltrainer, der als App (PWA) installiert werden kann.

## Installation als App

Damit die App installiert werden kann, muss sie über einen Webserver laufen (Browsersicherheitsrichtlinien).

1. Doppelklicke auf die Datei `Start_Server.bat`.
2. Öffne die angezeigte Adresse (`http://localhost:8000`) in Google Chrome oder Edge.
3. Klicke in der Adressleiste rechts auf das Installieren-Symbol oder auf den "Installieren"-Button in der App.

**Hinweis:** Wenn du die Datei `index.html` direkt öffnest, wirst du eine Warnung sehen, dass die Installation nicht möglich ist. Das ist normal und liegt an den Sicherheitsfunktionen von Browsern.

## Features
- Offline-fähig (nach Installation)
- Karteikarten, Multiple Choice, Tippen, Diktat
- Fortschritts-Statistik
- Dunkelmodus
- Keine Werbung, keine Kosten
